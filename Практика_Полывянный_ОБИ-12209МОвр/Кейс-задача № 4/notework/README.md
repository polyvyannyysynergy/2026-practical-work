# NoteWork

Прототип мобильного приложения для деловых заметок (кейс-задача № 4 производственной практики).

## Запуск

```bash
npm install
npx expo start
```

Откроется консоль Expo с QR-кодом. На телефоне нужно установить приложение **Expo Go** (App Store / Google Play) и отсканировать код - приложение откроется в Expo Go без установки.

Альтернативно можно открыть веб-версию (в браузере, без устройства):

```bash
npx expo start --web
```

В веб-режиме данные не сохраняются между сессиями (используется ин-мемори хранилище). На устройстве работают оба режима - SQLite и файлы.

## Структура

```
src/
  types.ts                — модель Note и SearchQuery
  navigation.ts           — типы маршрутов
  theme.ts                — палитра и отступы
  seed.ts                 — демо-данные для веб-режима
  repositories/           — слой хранения (SQLite, файлы, in-memory)
  context/                — React-контекст репозитория
  hooks/                  — useNotes, useDebouncedValue
  components/             — карточка заметки, пустое состояние, панель фильтров
  screens/                — список / редактор / настройки
```

Стек: Expo SDK 54, React Native 0.81, TypeScript.
